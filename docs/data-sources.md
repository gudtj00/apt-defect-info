## 0-5. 공공누리 유형 확인 — ✅ 완료 (2026-08-04 추가 실사)

브라우저로 각 데이터 페이지에 직접 들어가 라이선스 표시를 확인했다. 텍스트로는 "이용허락범위 제한 없음"만 보이고 배지 이미지는 안 보여서, data.go.kr의 공식 이용정책 페이지(`/ugs/selectPortalPolicyView.do`)에서 이 문구의 의미를 먼저 확인했다.

### 핵심 발견: "이용허락범위 제한 없음" = 사실상 공공누리 제1유형과 동일

공공데이터 관리지침 제8조③: 공공기관이 업무상 작성해 공표했거나 저작재산권 전부를 보유한 저작물은 "이용자가 별도의 이용허락 없이 자유롭게 이용할 수 있도록 제공해야 한다." data.go.kr의 API/파일데이터 대부분은 애초에 "저작물"로 분류되지 않는 순수 행정 데이터(주소, 날짜, 숫자)라서 공공누리 제1~4유형 배지 자체를 안 붙이고 "이용허락범위 제한 없음"이라는 상위 문구로 대체한다. 이건 제2·4유형(비상업적 이용만 가능)보다 명백히 넓은 조건이며, 제1유형(출처표시 + 상업적 이용 가능 + 변형 가능)과 실질적으로 동일하다.

## 0-1. K-apt 시공사 필드 채움률 — ✅ 확인 완료. **GO.**

**결론: `kaptBcompany` 99.35%, `kaptUsedate` 99.76% 채움. 브리핑의 GO 기준(80% 이상)을 압도적으로 초과. 축①은 생존한다.**

### 실측 방법
- 사용자가 data.go.kr에서 15058453(공동주택 기본 정보제공 서비스)과 15057332(공동주택 단지 목록제공 서비스)에 대해 자동승인 인증키를 발급받아 전달함.
- `pipeline/phase0_kapt_fillrate_check.mjs` (Phase 0 실사 전용 일회성 스크립트, 제품 코드 아님)를 작성해 실행:
  1. `AptListService3/getTotalAptList3`로 전국 단지 수 확인 → **총 22,257개 단지**가 K-apt에 등록되어 있음.
  2. 전체 페이지에 고르게 스프레드해서(지역 편중 방지) **1,240건** 샘플링 — 서울·경기부터 세종까지 전국 15개 시도 전부 포함.
  3. 각 kaptCode로 `AptBasisInfoServiceV4/getAphusBassInfoV4` 상세 조회 → `kaptBcompany`, `kaptUsedate` 값 수집.
- **원본 응답 전체는 `raw/kapt_fillrate_raw.json`, `raw/kapt_sample_codes.json`, `raw/kapt_fillrate_summary.json`에 보관.**

### ⚠️ 측정 중 발견한 함정 (기록해둠 — Phase 2 파이프라인에서 반드시 재사용할 것)
1차 실행 결과가 "시공사 6.6%, 서울만 38.5%, 나머지 전 지역 0%"로 나와서 원본 응답을 직접 대조했더니 **실제 데이터 문제가 아니라 스크립트 버그**였다:
- data.go.kr는 트래픽/속도 제한에 걸리면 정상 응답(`response.header.resultCode`)이 아니라 **다른 래퍼 구조**(`OpenAPI_ServiceResponse.cmmMsgHeader.errMsg`)로 응답한다. 이걸 별도로 감지하지 않으면 "필드가 원래 비어있다"고 오판하게 된다.
- 동시성 8 + 지연 없음으로 1,160건을 몰아서 호출했더니 대부분이 이 에러 래퍼로 돌아왔다.
- **해결**: `resultCode !== "00"` 또는 `OpenAPI_ServiceResponse` 래퍼 감지 시 최대 5회 재시도(지수 백오프), 동시성 3, 요청당 80ms 지연으로 낮춤 → 재실행 결과 **API 오류 0건, 전체 정상 응답.**
- **교훈**: 이 API로 대량 수집하는 배치(Phase 2 이후 실제 파이프라인)는 반드시 이 에러 래퍼 감지 + 재시도 로직을 갖춰야 한다. 안 그러면 "채움률이 낮다"는 착각으로 잘못된 설계 결정을 내리게 된다 — 실제로 이번에 하마터면 그럴 뻔했다.

### 최종 수치 (1,240건, 전국 15개 시도)
| 필드 | 채움률 | 비고 |
|---|---|---|
| `kaptBcompany`(시공사) | **99.35%** (1,232/1,240) | 공백 문자(`" "`)만 있는 사실상 빈 값 3건을 빈 값으로 재분류해 반영한 수치 |
| `kaptUsedate`(사용승인일) | **99.76%** (1,237/1,240) | |

지역별로도 거의 전부 100%(경기 320건·서울 200건·전남광주통합특별시 100건 포함 전 지역)이며, 편중 없이 고르게 높다.

빈 값 3건은 전부 서울/전남광주통합특별시의 특정 소규모 단지(`로얄팰리스스위트`, `명일진로`, `부성`)로, 시공사 필드가 완전 공백 문자만 들어있고 사용승인일도 비어있음 — 개별 단지 데이터 등록 누락으로 보이며 지역/규모 패턴은 없음. 실제 서비스에서는 이런 케이스를 "정보 없음"으로 처리하면 된다(브리핑의 원칙과 일치).

### 판정
**80% 이상 → 그대로 진행.** 축①(단지별 담보책임기간 계산기)은 K-apt 데이터로 생존 가능하며, "시공사 정보 없음" 처리가 필요한 단지는 전체의 1% 미만으로 예상보다 훨씬 적다.

### 참고 — 확인된 API 세부사항
- 필드명(`kaptBcompany`, `kaptAcompany`, `kaptUsedate`, `kaptdaCnt`, `kaptDongCnt`, `kaptAddr`, `doroJuso`, `bjdCode`, `codeSaleNm`, `privArea`)이 V4(`AptBasisInfoServiceV4`)에서도 브리핑 가정 그대로 존재함을 실제 호출로 확인.
- 이용허락범위 "제한 없음", 무료, 자동승인 — 확인됨. 정확한 공공누리 배지 유형(1~4)은 여전히 텍스트로 노출 안 됨(육안 확인 필요, 낮은 우선순위).
- K-apt 자체 엑셀 일괄다운로드(`k-apt.go.kr`)는 봇 차단으로 스크립트 접근 불가 — 하지만 이제 필요 없다. OpenAPI만으로 축①에 충분하다.

「공동주택 하자의 조사, 보수비용 산정 및 하자판정기준」(국토교통부 고시 제2026-360호, 2026-07-08 공포) 전문을 국가법령정보센터 원문으로 전부 읽었다. 원문 파일은 `raw/law/`에 전체 보관.

### 확인된 것
- **총 130개 조문, 정확히 브리핑 숫자와 일치.** 제1장 총칙(제1~6조의2) → 제2장 하자 여부 판정(제7~44조, **38개**) → 제3장 조사방법(제46~84조, **39개**) → 제4장 보수비용 산정(제85~126조, **40개** — 제85조는 구성항목 정의라 유형 목록에서 제외하면 42개조 중 조사 대상은 40개 유형) → 제5장 보칙(제127~130조) → 부칙.
- **별표 17개, 브리핑과 정확히 일치.** 제115조②이 "별표 17과 같다"로 마지막 별표를 참조함(바닥구조 하자보수비 산정).
- **층간소음은 이 고시에 등장하지 않는다** — 브리핑 예상과 일치. 제35조(바닥구조)가 바닥구조 구성층 두께 부족·측면 완충재 누락·재료 품질 미달을 하자로 규정.
- 구체 수치들 원문으로 재확인:
  - 콘크리트 균열: **0.3mm 이상 = 하자**(제7조①). 0.3mm 미만이어도 누수 동반/철근길이방향 균열/관통균열이면 하자(제7조②).
  - 타일: 뒤채움 면적 **모르타르 떠붙이기 공법 80% 미만 시 하자**(제18조②), 접착강도 0.392MPa(4kgf/cm²) 이상이면 하자 아님(제18조③).
  - 결로: TDR(온도차이비율) 기준 또는 열화상카메라+표면온도계로 노점온도 이하 판단(제15조①).

### ⚠️ 새로 발견한 중요 사항 — 계산 엔진에 반영 필요
- **제127조(하자담보책임기간 경과사건)**: "하자담보책임기간 내에 하자보수를 청구하지 아니한 사건은 심리하지 아니한다. 다만, **2016년 8월 11일 이전에 사용검사를 받은 공동주택**은 하자담보책임기간 내에 하자가 발생한 사실이 입증되는 사건의 경우에는 그러하지 아니하다." → 브리핑이 우려했던 "2016년 전후 기준 변경"이 **실제로 존재함이 확인됨.** 단, 이건 담보책임기간의 길이 자체가 바뀐 게 아니라 **"기간 내 발생 사실 입증"으로 청구 가능 여부를 구제하는 예외 규정**이다. 2016.8.11 이전 준공 단지를 다룰 때는 이 예외를 UI/계산 로직에 별도 고지해야 한다.
- **부칙 <제2025-58호>**: "제35조제2항, 제72조 및 제115조의 개정규정은 **2022년 8월 4일 이후** 「주택법」 사업계획승인을 신청한 경우부터 적용한다." → 바닥구조(층간소음 인접 이슈) 판정기준은 준공 시점에 따라 다른 조문이 적용된다. 이건 담보책임기간과는 별개로, 하자 판정기준 자체가 준공 시점별로 갈리는 사례이므로 Phase 3(하자 유형 사전) 설계 시 반영 필요.
- 고시 개정 이력 전체: 2015.12.17(최초) → 2016.12.30 → 2020.12.1 → 2021.11.23 → 2025.2.3 → 2026.7.8(현행, 정부조직 개편 반영).

### 확인 안 됨
- 이 고시의 공공누리 라이선스 유형 — 법령/행정규칙 원문 자체는 통상 저작권 제한이 없는 공공저작물이지만, 재게시 시 출처 표기 방식은 확인 필요.
